# 电磁学二轮讲义 · 七模块合订版

七个模块统一目录、连续正文页码和PDF书签，共708道例题、练习与综合题。保留2026年10月21日统一复核后的题干、解答、题号、图号与过程图。

合订本共1330个PDF页面，正文连续编号1—1326，含总目录和分层书签。

[下载合订PDF](dist/电磁学二轮_七模块合订版.pdf?raw=1) · [LaTeX全书入口](main.tex)

- dist/：合订PDF。
- main.tex：全书入口；preamble.tex、frontmatter.tex：共用版式、字体和封面。
- chapters/：七模块可编辑LaTeX正文。
- tikz/：正文实际引用的可编辑TikZ源码。
- assets/：编译正文所需的矢量图及保留的原理论插图。
- figures.json：TikZ与矢量资源的对应表。
- build.py：重编译脚本。

## 编译

安装Python 3、含XeLaTeX的TeX Live或MacTeX，在仓库根目录运行：

    python3 build.py

此命令使用已附的矢量图编译全书。修改TikZ后，运行：

    python3 build.py --figures

该选项先重编译所有实际引用的TikZ，再生成合订PDF。原字体可用时保持原排版；缺少macOS字体时自动回退到TeX Live自带字体。回退字体可能改变分页。
